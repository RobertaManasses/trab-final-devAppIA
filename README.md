# Projeto Final de DevApp com IA

## 1. Objetivo do Projeto
Este projeto tem como objetivo desenvolver um app, com sistema de login, que tenha um chat para fazer perguntas para uma IA. O tema do documento que a IA se baseia é o PPC do Curso de Licenciatura em Computação.

---

## 2. Como Instalar e Rodar o Projeto

Clone o repositório do GIT.
Navegue até a parta raiz.

### GIT
https://github.com/RobertaManasses/trab-final-devAppIA



Após baixar o projeto:
### Terminal 1:
cd api-usuarios
npm start

### Terminal 2:
cd app
npm start
